## 💡 Why this project?

When a BSOD hits, most people either panic or spend 30 minutes searching forums for an answer.

This tool gives you **one place** to look up any error code and immediately understand what went wrong and how to fix it — written in plain language for both IT professionals and everyday users.

**Got a blue screen on someone else's PC?** Just send them the link to [bsod-guide.web.app](https://bsod-guide.web.app/) — they can search the code themselves and follow the fix without any technical knowledge.
